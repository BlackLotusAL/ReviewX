# Bundled interface fonts

The original, unmodified variable WOFF2 files are served locally. Both use the SIL Open Font License 1.1; the original license files are included beside the fonts.

- `inter-variable.woff2`: Inter 4.1, `web/InterVariable.woff2` from https://github.com/rsms/inter/releases/tag/v4.1. License: `Inter-LICENSE.txt`.
- `geist-mono-variable.woff2`: Geist Mono 1.7.2, `geist-font/GeistMono/webfonts/GeistMono[wght].woff2` from https://github.com/vercel/geist-font/releases/tag/v1.7.2. License: `Geist-OFL.txt`.

No font CDN or build-time font download is required. Chinese text uses the user's system fonts.
