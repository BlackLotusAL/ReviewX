REVIEWX · NATIVE AGENT V2

原生 Agent 检视架构

ReviewX 固定输入、权限和输出合同；OpenCode 负责原生工具调用、子代理上下文和逐问题复核。模型沿用用户配置的默认模型。

一条主流程

固定 Git 版本与规则→四个独立检视任务→候选去重→逐条新会话复核→结构化 JSON→固定脚本渲染

两个规则代理、两个缺陷代理使用 OpenCode 原生 task。调度由提示词驱动，不再通过宿主端工具收据、材料阅读配额或全历史重放进行结果验收。

检视可读取 source/base、diff 和按目录作用域冻结的 AGENTS.md、CLAUDE.md；只开放固定 Git 查询。禁止修改、构建、测试、脚本执行和评论发送。

职责边界

组件责任异常边界
Git 准备固定 source/target/base，构造只读检视工作区，冻结规则失败只影响当前 attempt
OpenCode 适配启动服务、原生会话、读取最终消息；SSE 仅观察丢失生成响应时查询原会话，不重发生成
结构化输出字段类型、必要内容、路径与行范围等基本检查最多一次无工具修复；保留有效条目，异常条目隔离并标记 partial
固定渲染严重级别、标题、标签、描述、位置、影响、解决方案、预防建议UI、报告、发布复用同一份冻结正文
持久化与队列不可变报告与状态引用，全局 FIFO持久化失败或进程退出未确认时暂停，保留队列，支持恢复
发布用户逐条确认后发送已有正文失败或结果未知不自动重发，不拖停检视队列

完成、部分完成与失败

完整检视且无问题才是 PASS。缺少上下文、未完成复核或隔离异常意见均是 partial；有效意见仍可确认发送。单任务失败继续后续任务。目录清理与日志失败作为警告，不推翻已保存结果。

进程退出未确认时先保存可用结果，再暂停队列。恢复会重试清理和残留进程检查，不重新生成已有检视。应用重启保留排队项，执行中任务标为停止。

独立数据与证据

新目录：%LOCALAPPDATA%\ReviewX\native-v2。state.version=2；不迁移、不删除旧数据。每份报告保存结构化结果、原始输出、可选修复输出和执行信息。
